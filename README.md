# Project Reflection Report: Bootstrap 5 UI Exploration

## 1. Step-by-Step Implementation Process
1. **Setup**: Created clean HTML5 file structures (`index.html`, `about.html`, `contact.html`) linked to standard Bootstrap 5 CDN, Bootstrap Icons, and a custom `style.css` file[cite: 1].
2. **Component Collection**: Reviewed official Bootstrap 5 documentation to extract navbars, hero components, cards, forms, and modals[cite: 1].
3. **Remixing & Custom Styling**: Combined separate components into unified layout structures, using Bootstrap utility classes alongside custom CSS rules (gradient hero section, hover animation effects on cards) for enhanced visual appeal[cite: 1].
4. **Responsiveness**: Ensured proper grid layout behavior across mobile, tablet, and desktop breakpoints using Bootstrap `col-md-*` and `col-lg-*` containers[cite: 1].
5. **Deployment**: Uploaded repository code to GitHub and published live through GitHub Pages / Netlify[cite: 1].

## 3. Challenges & Solutions
- **Challenge**: Modals and togglers not working dynamically.
  - **Solution**: Confirmed `bootstrap.bundle.min.js` was correctly included before the closing `</body>` tag on every page[cite: 1].
- **Challenge**: Keeping the footer pushed to the bottom of pages with small amounts of text.
  - **Solution**: Used Flexbox helper classes (`d-flex flex-column min-vh-100` on body and `mt-auto` on footer)[cite: 1].
